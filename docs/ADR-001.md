# ADR-001: Separate Core API and AI Service

## Status

Accepted

## Decision

FitFlow uses a NestJS service for core product workflows and a separate FastAPI service for workout generation and machine-learning workloads.

## Rationale

This keeps transactional business logic independently deployable from Python-based model code while allowing each service to use its strongest ecosystem.
